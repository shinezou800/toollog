# Toollog

Toollog 是面向手机使用的工具记录与验证项目。此分支在 React + TypeScript + Vite 本机 MVP 上增加 **Supabase Free 私密云端版本**：唯一管理员登录、工具与手记云端读写、版本冲突保护、导出和需另行确认的旧数据导入。先做响应式网站，完整 PWA 为后续可选项。

> 状态：云端实现候选，**真实 Supabase 项目接入与两设备验证待完成**；无配置时只显示锁定页，不回落本机保存。旧本机 MVP 与原浏览器数据不自动替换。没有公开部署、开通付费资源或导入真实旧记录。测试环境和真实验收以 PR 验证记录为准；Altare、Gemini 和完整 PWA 均未执行。

## 本地预览

需要 Node.js 24 LTS（见 `.nvmrc`）、npm，以及你名下的 Supabase **Free** 项目。先按 [Supabase 配置与权限核对](supabase/README.md) 设置唯一管理员、关闭注册并应用 RLS 迁移，将 `.env.example` 复制为被 Git 忽略的 `.env.local`，只填项目 URL 与 publishable key；不需要把 service_role 密钥交给网页。未配置时可以构建，但不能登录或保存。

```sh
nvm use # 不使用 nvm 时，安装 Node.js 24 即可
npm ci
npm run dev
```

打开终端显示的本地地址。手机与电脑在同一可信网络时，可以用电脑的局域网 IP 和终端显示的端口访问。开发服务器默认监听 `0.0.0.0`，仅供本地演示，不要暴露到公网；只需本机访问时可用 `npm run dev -- --host 127.0.0.1`。

检查与生产构建预览：

```sh
npm test
npm run build
npm run preview
```

构建输出到 `dist-cloud/`，不覆盖旧原型仍在使用的 `dist/`。私密预览使用生产构建；访问授权由 Devin 代理提供，仍依赖管理会话的生命周期。Supabase 数据 API 有公网地址，但匿名和非管理员不能访问业务记录。

### 此分支的代码功能（真实服务结果另见 PR）

- 管理员邮箱密码登录、退出；无公开注册、账号自动提升或本地模式兜底。登录授权失败不展示工具库；退出即卸载记录页面，云端记录不写入旧 localStorage 数据区。
- 所有应用表（工具、手记、内部控制表）均 ENABLE + FORCE RLS。唯一管理员由管理端绑定 UUID，客户端无修改绑定的权限；匿名和其他已登录账号均不能读写。客户端只能通过显式授权检查的事务 RPC 写入。
- 工具和手记分表保存；全库 revision 与控制行锁防止跨设备陈旧覆盖。字段、日期、长度、枚举、重复 ID 及意外删除在数据库校验；失败不报告成功，保留当前草稿。
- 刷新、返回工具库或切回页面时重新读取；编辑页不被后台刷新替换。JSON 导出先读最新云端，不拿离线缓存冒充最新。
- 旧数据原始备份、JSON 文件/本机数据预检、逐条展示、数量及冲突检查。**导入默认在界面和服务端锁定**，等所有者确认已备份、允许上传后才解锁；本机副本从不自动删除。

### 沿用原型的界面能力

- 手机优先工具库，含桌面布局、关键词搜索、分类和使用状态组合筛选、数量统计及空状态。
- 工具详情、官网链接、试用手记列表；新增和编辑工具与手记，包含日期、使用环境、结论和笔记。
- 字段校验、保存成功/失败反馈、离开未保存表单的提醒，以及原样保留手记空白、换行和 emoji。
- JSON 导出备份。首次打开为空，可明确选择载入合成示例；云端版选择后会保存到云端，示例不代表真实测评，也不调用 AI 或第三方测评 API。
- manifest、SVG/PNG 图标和 standalone 显示配置；**没有 service worker、离线缓存或完整 PWA 保证**。
- Vitest 原型存储回归、云端错误/账号隔离界面、迁移和密钥构建护栏测试；真实 PostgreSQL RLS/事务测试见 `supabase/tests`。GitHub Actions 运行两者和构建，实际执行结果查看 PR，不把配置视为通过。

### 数据与当前边界

**旧原型数据**仍只属于原浏览器和来源（协议、域名/IP、端口）。新版本或新网址不能读取其他来源，需先在原浏览器导出备份，预检后等待所有者确认再上传；从不静默清空旧数据。云端数据库与登录信息由 Supabase 托管，不进 GitHub；本机只持久化 Auth 会话以支持重开登录，不缓存云端记录。

本轮不做：删除、多人协作、离线写入/冲突自动合并、即时推送、共享直达详情、完整离线 PWA、公开部署、付费资源、邮件找回密码服务。全库快照最多约 2 MB/1000 个工具，适合单管理员初版，不是大规模协作架构。Supabase Free 一周不活跃可能暂停，没有免费自动数据库备份保障，需定期导出。实体 iPhone 与手机尺寸模拟分别记录，不把原型的旧测试当成云端验证。

### 快速演示路径

1. 使用已配置的唯一管理员登录；测试仅用合成数据。可选择「先看看示例」浏览工具，尝试搜索和状态/分类组合筛选。
2. 点击工具进入详情，编辑介绍并保存。
3. 点击「写手记」，填写日期、环境和体验，保存后再次编辑。
4. 返回工具库并刷新，再从独立浏览器会话登录，确认读取同一份云端记录；点击「导出备份」。实际通过情况见 PR。

测试与构建的实际结果以 PR 的验证记录和 CI 为准；桌面模拟不能代替真实 iPhone 人工复核。

## 目标与范围

- 构建 mobile-first 的工具记录体验：在手机上方便地查看、添加和整理工具条目及其验证结果，保持操作清晰。
- 前端使用 **React + TypeScript + Vite**，以 **PWA** 方式提供可安装的移动网页体验；桌面浏览器也应可用。
- 后端改用 **Supabase Free：Postgres + Auth + RLS**，经所有者批准替代初始 Cloudflare Worker/D1 方向，以减少自建认证和会话维护。项目需核实免费、免绑卡和数据访问范围；不启用付费资源。
- 使用 **Vitest** 做单元和组件测试，**Playwright** 做端到端测试，**GitHub Actions** 运行持续集成。
- 与 Devin Bot 协作时，以小步任务、清晰验收标准和可审查的结果为原则；每次变更说明做了什么、如何验证、失败或阻塞在哪里。

## 体验与实现要求

### 前端与 PWA

- 采用适合窄屏的布局和触控控件；常见手机尺寸下不应出现妨碍使用的横向溢出。
- 为主要操作提供明确的加载、空状态、成功与错误反馈；基本操作应支持键盘和可访问名称。
- 配置 PWA 所需的 manifest、图标和缓存策略；离线体验仅在明确实现和测试后宣称支持，不能静默丢失用户更改。
- 前后端边界清晰，输入需验证；不把 API 密钥、凭据或敏感数据打包进前端或提交到仓库。

### 数据库与认证

- 使用 Supabase 的 Auth 与 PostgreSQL RPC；迁移、RLS、管理员绑定与导入解锁说明均可审查。数据库变更可追踪、可重复应用，错误有可理解的反馈。
- 在服务端验证输入并限制不必要的数据暴露；生产密钥只放在平台提供的安全配置中，不写入代码、提交记录、日志或公开测试结果。
- 本地或测试环境优先使用合成数据，不依赖真实个人信息；部署与用量受免费额度和实际账户条件约束。

## 验证计划

### 自动化测试和持续集成

1. Vitest 覆盖关键数据处理、输入校验、核心交互及错误分支；测试结果要可在本地复现。
2. Playwright 覆盖关键用户流程、移动视口及基本可访问性；使用隔离的测试数据，避免触及真实账户或产生费用。
3. GitHub Actions 在合适的提交或拉取请求上运行安装、构建和测试。按实际免费额度设置运行频率和用量，若存在收费风险则停止，不能自动升级。
4. 测试失败应显示清楚的失败位置和复现方法；不能把跳过、模拟或等待中的测试标记为通过。

### Gemini API 免费层：合成 JSON 测试

- 确认当前账户和模型确有免费额度、不会产生费用后，使用**合成输入**发起最小范围的 Gemini API 测试；如果免费额度不可用或需要付费，停止并记录阻塞。
- 要求返回结构化 JSON；检查返回内容能解析，并验证约定的字段及类型。记录通过、失败、限流或不可用等结果，但不要提交密钥、请求凭据或个人信息。
- 限制调用次数，避免无界重试；遇到配额、计费或访问限制时停止，不切换到收费服务。
